# 담당자 대시보드 카드 해석

한 번의 분석 실행에서 계산된 집계 수치를 받아 인천시 담당자가 정책 판단에 활용할 다섯 카드의 해석을 만드십시오.

## 입력

입력은 다음 일곱 집계를 가진 JSON 객체입니다. 개인별 항목이나 원문 발화는 포함되지 않습니다.

- `kpi`: 참여자 수, 요구 총 건수, 참여 자치구 수, 집계 연령 최솟값과 최댓값
- `ages`: 네 연령대의 성별 참여자 수
- `regions_count`: 자치구별 참여자 수
- `topics`: 계획 부문별 요구 건수와 참여자 수
- `cross`: 계획 부문별 네 연령대 요구 건수
- `axis_stats`: 도시가치 4축의 축 이름 `display`와 극별 인원수, 평균 강도
- `type_distribution`: 도시 유형별 참여자 수

극 글자의 뜻은 다음과 같습니다. 축과 극의 이름을 새로 지어내지 말고 이 이름을 그대로 쓰십시오.

- 생활 리듬: `A` 활기찬, `C` 여유로운
- 선호 공간: `U` 도시적인, `N` 자연친화
- 우선 가치: `O` 기회, `W` 돌봄
- 발전 가치: `F` 새로움, `H` 이야기

도시 유형 코드는 네 축의 판정 글자를 축 순서대로 이어 붙인 것입니다. 예를 들어 `CNWH`는 여유로운·자연친화·돌봄·이야기입니다.

## 작성 규칙

- `map`은 자치구별 참여자 수, `topics`는 계획 부문별 요구, `axes`는 도시가치 4축, `cross`는 연령대별 요구사항 교차표, `types`는 도시 유형 분포를 해석하십시오.
- 입력에 있는 수치만 근거로 삼고 입력에 없는 수치를 만들지 마십시오.
- 수치를 단순히 반복하지 말고 담당자가 정책 판단에 쓸 수 있도록 그 수치가 무엇을 시사하는지 쓰십시오.
- 이 결과는 자발적 참여 표본이므로 인천 청년 전체를 대표하지 않는다는 한계를 해석에 반영하십시오.
- 각 카드의 값은 2~4문장으로 쓰십시오.
- 문장 안에서 강조하고 싶은 부분은 `<b>`와 `</b>`로 감쌀 수 있습니다. 화면은 이 태그를 그대로 렌더링합니다.

## 출력 형식

`map`, `topics`, `axes`, `cross`, `types` 다섯 키를 가진 JSON 객체만 출력하십시오. 각 값은 문자열 하나이며 코드블록이나 설명 문장으로 감싸지 마십시오.

```
{
  "map": "string",
  "topics": "string",
  "axes": "string",
  "cross": "string",
  "types": "string"
}
```
