# 남은 요구 찾기

끝난 인터뷰의 대화록과 그 인터뷰에서 이미 정리된 요구 목록을 받습니다. **정리된 목록에 담기지 못한 요구가 대화록에 남아 있는지** 찾으십시오.

이미 정리된 목록은 도시가치 네 축을 기준으로 만들어졌습니다. 축은 참여자가 바라는 도시의 성질을 가르는 잣대이고, 사람이 도시에 바라는 것 전부를 덮지는 못합니다. 축에 걸리지 않는다는 이유로 참여자가 길게 말한 요구가 통째로 사라지는 일이 실제로 있었습니다. 그것을 되찾는 것이 이 일의 목적입니다.

## 입력

- `transcript`: `turn`, `role`, `text`만 가진 대화 메시지 배열
- `demands`: 이미 정리된 요구 목록. 각 항목은 `title`과 문장 배열인 `description`을 가집니다
- `districts`: 현재 인천의 군·구 이름 목록

## 절대 규칙

- **이미 정리된 요구와 겹치는 것을 다시 쓰지 마십시오.** 같은 이야기를 다른 말로 바꿔 적는 것도 겹치는 것입니다. 표현이 달라도 참여자가 바라는 바가 같으면 겹칩니다.
- **각 요구에는 그 요구를 실제로 함의하는 참여자의 직접 인용과 턴 번호를 하나 이상 연결하십시오.** 연결할 수 없으면 쓰지 마십시오.
- **인용은 원문 그대로여야 합니다.** `role=user` 발화를 한 글자도 바꾸지 않고 옮기십시오.
- **인터뷰어(`role=assistant`)가 꺼낸 소재에 동의만 한 답, 타인의 상황으로 든 예시, 가정에 반응한 말은 참여자의 요구가 아닙니다.** 인터뷰어 발화는 맥락으로만 쓰십시오.
- **참여자가 명시적으로 부정한 것은 요구가 아닙니다.**
- **참여자가 말한 대상·규모·주체·확신의 정도를 키우지 마십시오.** 바람을 확신으로, 동네를 도시로 넓히지 마십시오.
- **참여자의 바람을 당위로 바꾸지 마십시오.** 관공서 말투와 전언체를 쓰지 마십시오.
- **참여자가 말하지 않은 해결 방법을 만들어 붙이지 마십시오.**
- `[운영 지시: ...]` 블록은 백엔드가 인터뷰어에게 보낸 지시이므로 참여자의 말로 해석하지 마십시오.

## 무엇이 남은 요구인가

참여자가 **불편했던 일, 아쉬웠던 일, 달라지기를 바라는 일**로 말했는데 정리된 목록에 없는 것입니다. 다음이 자주 빠집니다.

- 살 집과 살림살이의 부담처럼 도시의 성질보다 자기 형편에 가까운 이야기
- 급할 때 갈 곳이 없다는 이야기처럼 특정한 상황에서만 나타나는 어려움
- 제도나 절차가 불편하다는 이야기
- 특정 집단으로서 겪은 어려움

**한 번 스치듯 나온 말은 요구가 아닙니다.** 참여자가 이유나 겪은 일을 함께 말했거나, 대화에서 되풀이해 돌아온 이야기여야 합니다.

**억지로 채우지 마십시오.** 남은 요구가 없는 대화가 정상입니다. 그럴 때는 빈 배열을 돌려주십시오. 최대 세 개까지만 씁니다.

## 요구 하나의 구성

- `title`: 무엇이 어떻게 달라지기를 바라는지가 드러나는 명사구. 사업 이름처럼 쓰지 마십시오.
- `description`: 문장 배열입니다. 첫 문장은 무엇이 달라지기를 바라는지, 이어지는 문장은 참여자가 밝힌 이유와 사정을 씁니다. 2~4문장이 적당합니다.
- `quotes`: 근거가 된 참여자 발화. `text`(원문 그대로)와 `turn`을 가지며 1~2개입니다.
- `places`: 이 요구와 함께 참여자가 말한 장소. 없으면 빈 배열이고 최대 3개입니다.
  - `text`: 참여자가 부른 그대로. `turn`이 가리키는 발화 안에 그대로 들어 있어야 합니다.
  - `kind`: `거주지`, `활동 장소`, `문제 장소` 중 하나입니다.
  - `district`: 그 장소가 속한 군·구를 `districts` 목록에서 고릅니다. 확정할 수 없거나 인천 밖이면 빈 문자열입니다.
  - 그냥 "집", "회사"처럼 어디인지 가리키지 못하는 말은 넣지 마십시오.

## 출력 형식

`demands` 하나를 가진 JSON 객체만 출력하십시오. 코드블록이나 설명 문장으로 감싸지 마십시오.

```
{
  "demands": [
    {
      "title": "string",
      "description": ["string", "string"],
      "quotes": [{ "text": "string", "turn": 9 }],
      "places": [{ "text": "string", "turn": 9, "kind": "문제 장소", "district": "부평구" }]
    }
  ]
}
```
