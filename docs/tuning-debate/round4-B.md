# 전문가 B — 4라운드 최종 통합안

## 0. 배포 결론

인터뷰어는 축을 완성하거나 정책 해법을 얻는 주체가 아니라 시민이 답할 수 있는 생활 경험 한 칸을 묻는 주체로 축소한다. 축 커버리지·종료 자격·악성 횟수·질문 선택·형식 정리·지역 정규화는 백엔드가 맡는다. `axes.md`는 그대로 둔다. 보고서는 시민 원문에 연결되지 않은 요구를 만들지 못하며, 근거가 없는 축은 빈 상태로 표시한다.

현재 기준 행 번호는 `system.md` 152행, `rubric.md` 97행이다. 아래 범위는 변경 전 파일 기준이다.

# 응답 형식

[[END_INTERVIEW]]
```
````

#### 제목 교체 근거

| 기존 | 최종 | 근거 |
|---|---|---|
| 아침, 하루가 시작되는 속도 | 아침에 눈을 뜰 때 | `속도`가 생활 리듬 축을 직접 공급하므로 시간 표지만 남겼다. |
| 집을 나서면 보이는 풍경 | 집을 나선 뒤 | `풍경`이 시각 묘사와 추상어를 먼저 정하므로 이동 시점만 남겼다. |
| 일하고 배우는 낮과 사람들과 있는 저녁 | 낮과 저녁 | 일·배움과 사람을 맞세워 기회·돌봄의 대리 항목을 공급하므로 시간대만 남겼다. |

#### 16문항 선택 근거

## 3. 백엔드 변경 명세

### 3.1 프리픽스·커버리지·질문 은행

- `api/app/prompts.py:37-43`의 `build_fixed_prefix()`에서 `knowledge.load_plan_summary()`를 제거한다. 인터뷰어 프리픽스는 `rubric + system + age`만 가진다.
- `api/app/prompts.py:46-110`의 표시 축명 기반 운영 지시를 질문 은행 선택으로 교체한다. 백엔드는 내부에서만 축별 증거 수를 보고 부족한 답칸을 고르며 모델에게 축·극 이름이나 균형 지시를 보내지 않는다. 커버리지 완료는 종료 필요조건이 아니다.

```json
{
  "id": "bank-2026-08-v1",
  "answer_key": "morning_wake_time",
  "coverage_axis": "AC",
  "variants": [{
    "variant_id": "default",
    "text": "2040년 쉬는 날 아침에는 몇 시쯤 눈을 뜨고 싶으세요?",
    "applicable_when": ["default"],
    "conflicts_when": []
  }],
  "qualification": {
    "main_clause_wh_count": 1,
    "pole_lexeme_count": 0,
    "abstract_lexeme_count": 0,
    "policy_lexeme_count": 0,
    "asks_lived_scene_or_action": true,
    "middle_school_vocabulary": true
  },
  "version": 1
}
```

- `coverage_axis`는 백엔드 전용이며 운영 지시에 직렬화하지 않는다. 한 `answer_key`에 기본형과 문맥별 변형 2~3개를 두고, 모든 변형은 여섯 자격 항목을 각각 통과해야 한다.
- 런타임에는 `ANSWER_KEY` 하나와 검수 변형들만 넣는다. 모델은 하나를 글자 그대로 고르고 앞에 되짚기 규칙을 통과한 평서문 하나만 붙일 수 있다. 은행은 커버리지 보충 턴에만 쓴다.
- `asked_answer_keys`, `declined_answer_keys`, `answered_answer_keys`를 세션에 저장한다. 명시적 거절 키는 다시 선택하지 않고, `모르겠다` 뒤 한 번의 축소 질문까지 실패한 키도 닫는다.

### 3.2 `termination_allowed`

- 세션에 백엔드 소유 불리언 `termination_allowed`를 둔다. 운영 지시 문자열로 모델에게 전달하지 않는다.
- 마지막 추가 발언 질문을 보낸 순간 `false`, 그 뒤 참여자 답을 저장한 순간 `true`다. 참여자가 명시적으로 중단을 요청한 경우에도 `true`로 전이한다. 애매한 중단 표현은 한 번 확인한다.
- `api/app/trailer.py`가 종료 토큰을 찾아도 비트가 `false`이면 무효화한다. 이미 생성된 마무리 문구가 노출되지 않도록 `api/app/interview.py:49-62`의 SSE 노출을 전체 응답 파싱 뒤로 미룬다.
- 무자격 종료 출력은 버리고 백엔드가 현재 유효한 은행 질문 하나를 그대로 보낸다. 비트가 `true`여도 답 요구 표면형이 있으면 종료를 보류한다. 이는 보조 가드이고 정상 종료에는 질문·청유·부탁이 0개여야 한다.
- 참가자 중단, 추가 발언 질문과 같은 턴의 종료, 청유형 뒤 종료, 토큰 줄 위치, 스트림 청크 경계를 각각 테스트한다.

### 3.3 악성 카운터

- `api/app/trailer.py`에 `[[MALICIOUS_RESPONSE]]`를 추가한다. 모델은 의미 판정만 하고 세션의 `malicious_count`는 백엔드가 증가시킨다.
- 1회면 모델 출력을 버리고 고정 경고문을, 2회면 고정 중단문과 `[[ABORT_INTERVIEW]]`를 내보낸다. 해당 턴의 동시 채점은 취소하고 증거와 일반 보고서 대화록에서 제외한다.
- 같은·다른 악성 발화 두 번, 긴 간격, 인용된 욕설, 짧은 답, 주제 이탈, 조사 불신, 역할 변경 지시를 고정 테스트한다. 카운트 정확도 100%, 비악성 경계 표본 카운트 0이 기준이다.

### 3.4 서식 스트립·질문 파서

- 제어 토큰을 먼저 분리한 뒤 줄 머리 제목·인용·불릿 표지, 강조 구분자, 단독 장식 문자를 결정적 규칙으로 제거한다. 뜻이 바뀔 수 있으면 수정하지 않고 출력을 버려 한 번 재생성한다.
- 스트립 전후 문장, 규칙 버전, 변경 위치를 로그에 남긴다. 형식 문자 노출률 0이 기준이다.
- 질문 파서는 1층 물음표 수와 2층 주절 의문사 수로 후보만 추린다. 최종 복합 질문 여부는 3층 독립 답칸 사람 라벨이 정한다.

### 3.5 지역 정규화

- 구조화 모델은 참여자 원문 `raw_region`만 반환한다. 백엔드는 버전이 있는 별칭 표로 `normalized_region`을 만들고 원문·표 버전·적용 규칙을 함께 저장한다. 집계에는 정규화 값만 쓴다.
- 옛 군·구명, 동·섬·생활권 별칭, 너무 넓은 값, 비인천 값, 다의적 값을 테스트한다. 확정할 수 없으면 `normalized_region=null`이다. 별칭 골드 정확도 100%, 미등록·다의 값 오정규화 0이 기준이다.

### 3.6 근거 충분성

`api/app/scoring.py:8-66`의 축 결과에 다음을 추가하되 계산식과 `axes.md`는 바꾸지 않는다.

```json
{"evidence_count": 0, "pole_weights": {"A": 0, "C": 0}, "empty_axis": true}
```

- `evidence_count`는 서로 다른 검증 근거 수, `pole_weights`는 양극별 가중치 합, `empty_axis`는 `evidence_count == 0`이다.
- 빈 축의 내부 기본 글자와 51은 호환을 위해 계산할 수 있지만 카드와 보고서에서 선호·강도로 설명하지 않고 `이 대화에서 확인할 근거가 부족합니다`로 표시한다.
- 한쪽 근거 한 건뿐인 축은 방향과 함께 `근거가 적음`을 표시한다. `strength`의 사용자명은 `대화 근거 비율`로 바꾼다. 설명 문구는 LLM이 아니라 코드가 만든다.

## 5. 검증 절차

### 5.1 층화 30과 이중 라벨

1. 실패 직전 상태에서 파서 점수 상위 10턴, 고정 난수 시드의 무작위 10턴, 파서 저값·0값 10턴을 고정한다. 상위만 뽑지 않아 거짓 음성을 본다.
2. 기존·개정 출력을 만들고 버전을 가린다. 턴 ID, 입력, 운영 지시, 출력, 실행 시각, 생성 설정, 모델 ID, 프롬프트·은행·파서 해시를 보존한다. 모델 버전이 바뀌면 별도 블록이다.
3. 두 평가자가 독립적으로 정보 단위 수, 새 후보·손실·인과, 반복, 대상·조건·범위·극성·정서 왜곡, 정책 해법 요구, 질문과 종료 동시 출력을 고정표로 판정한다.
4. 항목별 일치율과 Cohen's κ를 낸다. κ<0.80이면 불일치 원본으로 지침을 고쳐 다시 블라인드 라벨링한다. 희귀 항목은 원자료 일치율도 함께 낸다.
5. 최초 독립 라벨, 불일치 사유, 최종 판정을 모두 보존하고 같은 30턴을 다음 버전에 재사용한다.

통과 기준은 최종 사람 판정에서 복합 정보 단위, 새 후보·가상 대가·정책 해법 요구, 명시적 거절 뒤 반복, 질문과 종료 동시 출력이 각각 0건이며 되짚기 왜곡이 기존보다 감소하고 새 범주가 생기지 않는 것이다.

### 5.2 2×2 구조화 교차표

정화본은 사람이 편집하지 않는다. 해시가 고정된 규칙이 다음 순서로 기계 생성한다.

1. 되짚기에서 참여자가 대화 전체에서 한 번도 쓰지 않은 명사·동사를 찾는다.
2. 고정 대응표로 참여자 원어에 유일하게 되돌릴 수 있으면 치환하고, 아니면 그 구절을 삭제한다.
3. 들리다·보이다·있다·하다 예외는 문장 접합 용례에만 적용하고 독립 사실을 만든 용례는 치환·삭제한다.
4. 형용사·부사 승급과 정도·빈도·조건 삭제도 사전 고정 대응표로 원복한다. 표에 없는 사례를 사람이 즉석 수정하지 않는다.

| 대화록 | 구조화기 | 확인 항목 |
|---|---|---|
| 원본 | 기존 | 기준선 |
| 기계 정화본 | 기존 | 되짚기 오염 제거의 상한 |
| 원본 | 수정 | 오염 입력에 대한 구조화 방어력 |
| 기계 정화본 | 수정 | 결합 상한 |

기존 12대화 × 4조건, 총 48회다. 정화 조건은 새 프롬프트의 실제 효과가 아니라 반사실적 상한으로 보고한다. 요구별 인용 원문 존재·함의, 대상·규모·확신 확대, 인터뷰어 유래, 부정·타인 예시 반전, 조사 불신 보존을 이중 라벨한다. 수정 구조화기의 원본 조건에서 근거 없는 요구·부정 반전·인터뷰어 유래 요구 0, 인용 정확도 100%가 기준이다.

### 5.3 기준 `rubric.md:38` 반증 조건

기준 38행의 “얼마나 붐비고 있는지”가 생활 리듬 51을 희석했다는 가설은 다음 중 하나면 해당 사례에서 기각한다.

1. 근거 객체에 A 근거가 없고 `empty_axis=true`다.
2. A 근거가 있어도 38행 답이 아니라 자발 발화에서 나왔다.
3. 38행 답이 혼잡을 부정했는데 A로 태깅됐다. 이 경우 원인은 극성 판독이다.
4. 고정 대화록에서 38행 질문·답 쌍만 기계 제거해 재채점해도 C/A 가중치와 51이 같다.
5. 개정 문항 반복에서 질문 직후 A 근거 비율과 생활 리듬 51 집중이 사전 등록한 방향으로 줄지 않는다.

가설이 반증돼도 38행은 한 극을 전제하고 은행 자격을 통과하지 못하므로 교체한다. 반증되는 것은 (K)의 인과 설명이지 문항의 중립성 위반이 아니다.

### 5.4 파서 지표

- 1층: 물음표 수와 초과 후보율.
- 2층: 주절 의문사 수, 초과 후보율, 조건절 제외 오류율.
- 3층: 사람 골드 정보 단위 수, 1·2층 정밀도·재현율, 저값 10턴 거짓 음성 수.
- 은행: `ANSWER_KEY`별 선택률, 질문 exact-match율, 건너뜀률, 접속 문장 위반률.
- 되짚기: 신규 내용어, 조건·부정·정도 삭제 후보율, 사람 판정 왜곡률.
- 종료·형식: 무자격 종료의 발생·수용, 답 요구와 종료 동시, 토큰 줄 위반, 스트립·재생성·최종 노출률.
- 보고서: 요구별 유효 인용률, 인용 함의 실패, 빈 축 허위 요구, 불신 발화 보존율.
- 점수·지역: `evidence_count`, 양극 가중치, `empty_axis`, 빈 축 51 오표시, 정규화 정확도·결측·오정규화.

파서는 보조 지표다. 분포 하락만으로 개선을 선언하지 않고 층화 30으로 전체 발생률을 추정하지 않는다.

## 8. 상대 3라운드에 남은 위험

1. 아침 3문항은 내 종전 4문항보다 오염이 적지만 생활 리듬 관측 하나를 줄이고 `그런 아침의 이유`가 소리의 이유로 좁게 읽힐 수 있다. 최종안은 장소 대신 기상 시각을 넣었다.
2. 주절 의문사를 최종 판정으로 쓰면 조건절 오탐과 의문사 없는 복합 청유형 미탐이 남는다. 최종안은 물음표와 의문사를 후보 추출기로만 쓴다.
3. 명사·동사만 다루는 정화는 괜찮다→훌륭하다, 가끔→늘을 놓친다. 기계 정화에 고정 형용사·부사 대응표를 추가했다.
4. 악성 상태 이전을 보류하면 상태 부재가 남는다. 의미 판정은 모델에, 카운트와 출력은 백엔드에 두었다.

16문항은 여섯 자격 항목을 모두 통과한다. 관찰 대상으로 남긴 실패 문항은 없다.

## 9. 명시적 보류와 미실행

### 의도적으로 안 고치는 것

- **`axes.md` 정의·가중치·중복 규칙**: 이번에는 수정하지 않는다. J/K/L/M 최소 재현 뒤 판단한다.

- **인터뷰어가 만든 트레이드오프로 가중치 3을 늘리는 기능**: 의도적으로 복구하지 않는다. 자발 근거가 적으면 그대로 표시한다.
